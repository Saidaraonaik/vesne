## 1. Introduction

This quotation is for building and releasing the Vesne Field Execution and Proof Portal. The portal covers campaign setup, field proof, and client review for three roles: Admin, Executor, and Client.

The price below covers development, testing, and deployment. Maintenance is quoted separately.

## 2. Scope of work

**Admin**

- Sign-in and role-based access
- Clients, executors, projects, and work locations
- Proof review: approve or reject
- Dashboard, reports, and work map

**Executor**

- Assigned tasks
- Proof photo with location
- Submission history and profile

**Client**

- Project progress
- Approved proof gallery
- Reports and work map

**Platform**

- Web frontend connected to a Java backend
- Database for all records
- Secure login and role checks
- Photo storage
- Testing of the main flows
- Deployment on AWS
